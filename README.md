# صفائي — Android App

هذا مشروع Android حقيقي مبني حول نسخة صفائي الحالية، وليس مجرد صفحة ويب.

## ما فيه
- ملاحظات ومهام وصور وحفظ محلي.
- واجهة صفائي الحالية.
- WebView + JavaScript bridge.
- إشعارات Android أصلية للمهام المجدولة.
- طلب صلاحية الإشعارات على Android 13+.

## بناء APK
افتح المجلد في Android Studio ثم Sync Project with Gradle Files، وبعدها Build > Build APK(s).

ملاحظة: بيئة ChatGPT الحالية لا تحتوي Android SDK/Gradle قابلين للبناء، لذلك أعددت لك مشروع Android المصدر الجاهز للبناء، وليس APK موقّعاً.
